# 🥤 HolyDex

> **HolyDex ist wie ein Pokédex – nur für HOLY-Getränke.**
>
> *Das inoffizielle Nachschlagewerk für HOLY-Fans.*
>
> Entdecke alle HOLY-Getränke an einem Ort, bewerte deine Lieblingssorten und teile deine persönliche Sammlung mit anderen.

## ✨ Features

* 🥤 Übersicht aller HOLY-Sorten
* ⭐ Eigene Bewertungen vergeben
* 🔍 Schnelles Suchen und Filtern
* 📤 Bewertungen importieren und exportieren
* 🔗 Bewertungen per Link mit Freunden teilen
* 📱 Responsive Design für Desktop und Smartphone


---

## 🚀 Installation

```bash
git clone https://github.com/Kamiikaze/holy-dex.git

cd ./holy-dex

npm install

npm run dev
```

Die Anwendung ist anschließend unter

```
http://localhost:5173
```

erreichbar.

---

## 🏗️ Build
